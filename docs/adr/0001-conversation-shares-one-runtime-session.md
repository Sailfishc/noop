# 一段对话共用一个运行时会话

每条顶层消息原来都开一次全新的运行和全新的运行时会话，所以 Agent 不记得上一句，每句话都要重新 @，对话流读起来像派活。我们决定让一个人和同一个 Agent 连续的消息共用同一个运行时会话（一段对话），空闲 2 小时后结束，再说话时开新会话并从最近的消息里恢复上下文。

代价是会话越长每次调用越贵，早先的内容可能被运行时压缩；「线程是事实，会话是缓存」仍然成立，所以会话丢了只损失流畅，不损失事实。

## Considered Options

- 每条消息新开会话，把最近的消息塞进提示词：实现简单，但每次都重付整段上下文，工具调用的中间结果也带不过来。
- 会话永不结束：最像真人，但花费无上限，而且长会话的质量会下降。
